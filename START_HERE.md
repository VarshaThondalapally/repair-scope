# Start here

1. Open dist/index.html for the self-contained browser demo. No installation is needed for bundled examples.
2. Try Clear match, Unclear symptom, Companion work, and Spelling variant.
3. Select supported catalog rows, resolve companion checks, enter your name, confirm review, and approve the finding.
4. Download the reviewed draft CSV and JSON review record.
5. Read README.md, WALKTHROUGH.md, and docs/EVALUATION.md before using the project in outreach.

The bundled data is invented. This is an independent prototype, not an integration with any company. Ten Chromium acceptance tests passed in GitHub Actions, including actual downloads and custom uploads. See docs/VALIDATION.md for the evidence and remaining limits. A public hosted URL has not been verified.

For GitHub publication, authenticate the GitHub CLI in a network-enabled terminal and run Publish-GitHub.ps1. It uses the VarshaThondalapally account, never force-pushes, and starts the included test/build/Pages workflow. Check the workflow result before sharing a live URL.
