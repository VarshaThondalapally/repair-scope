# A 90-second demo

1. Explain the task: a technician's note must become supported lines from a fixed catalog, with a person deciding the repair scope.
2. Choose RV service and Clear match. Show the vent-lid candidate and literal evidence. Explain that the code comes from the selected catalog and the hours are synthetic.
3. Select the row, enter your reviewer name, confirm the review, and approve the finding. Show the approved count.
4. Add a finding. Try Unclear symptom. Show the clarification prompts and competing candidates. Explain that a water symptom cannot establish which component failed.
5. Try Spelling variant. Point to the visible possible spelling match. Explain that typo repair is lexical, not a diagnosis or language model.
6. For companion work, use Replace confirmed failed LP regulator, select RVS-0202, and show the example leak-test warning. Select the companion only after checking applicability. The alternative is an explicit, documented incomplete-draft override.
7. Download the CSV and review record. Show the reviewer, catalog snapshot, approval time, and exact rows. This is a portable draft, not a DMS integration.
8. End on the evaluation: original and current engines, unchanged development questions, remaining misses, and the need for independent labels from a practitioner.

For outreach, describe this as an independent prototype inspired by the publicly described inspection-to-repair-order handoff. Do not imply it was commissioned, integrated, independently evaluated, or used by vinny.
