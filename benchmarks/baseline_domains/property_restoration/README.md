**All data in this folder is invented.** The codes, descriptions, hours, rules and findings were made up for this project. Nothing is copied from, or modelled on, any real price list, estimating product or vendor code format, and the hours are not real labour times.

# property_restoration

A made-up line-item catalog for water, mold and fire restoration work.

| File | What it is |
|---|---|
| `catalog.csv` | 58 line items in 12 sections. Code format `PRS-SSNN` (section number, item number) is this project's own. |
| `rules.yaml` | 13 completeness rules ("extraction is followed by air movers", ...). |
| `synonyms.yaml` | Trade words that mean the same thing ("sheetrock" / "drywall", "black water" / "sewage"). |
| `gold.csv` | 38 technician-style findings with the expected code and expected companion lines, used by the evaluation. |
